A lightweight and responsive CGPA Predictor designed for Rajalakshmi Engineering College (REC) students.

Built using pure HTML, CSS, and Vanilla JavaScript.

---

# ✨ Features

- 📚 Add unlimited subjects
- ❌ Remove subjects dynamically
- 🌙 Dark/Light theme toggle
- 📱 Fully mobile responsive
- 💾 Saves data using localStorage
- ⚡ Lightweight and fast
- 🎯 Beginner-friendly clean UI
- 📊 Instant CGPA calculation
- 🔄 Reset functionality

---

# 🧮 CGPA Formula

```text
CGPA = Σ(Grade Points × Credits) / Σ(Total Credits)
```
